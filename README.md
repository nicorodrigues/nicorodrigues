## Hola, soy Nico 👋

Software Engineer · Technical Leader · Compulsive Builder, based in Buenos Aires, Argentina.

My projects usually start with "wouldn't it be cool if…" and then become much more elaborate than originally intended.

- 🏗️ I care about software architecture, and about automating anything I have to do more than twice.
- 🤖 Lately obsessed with autonomous, multi-agent AI systems.
- 🖥️ Running a homelab: bare-metal Linux, Tailscale, local LLMs, Docker, self-hosted everything.
- 🧊 Designing and 3D printing enclosures and gadgets (CAD included, failed prints not shown).
- 📱 Coming soon: iPhone apps built with React Native, Expo, TypeScript, Bun and Elysia, supervised by Moru the Yeti.
